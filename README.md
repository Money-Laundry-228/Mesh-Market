## Contribution Guide

### Templates
To get templates for Issue, Pull Request, etc.
Visit `docs/templates`

### Branch Strategy

- `<number-of-issue>-<name-for-the-feature>`

Example:
```
1-docker-integration
```

### Commit Convention

Follow _mostly_ [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/#:~:text=<type>%5Boptional%20scope%5D%3A%20<description>):

```
<type>[optional scope]: <description>
```

Example:
```
fix(www): add card component
```

### Code Style

- Use **Prettier** + **ESLint** + **clangd**  
- Prefer **TypeScript** over JS  
- Keep functions small and self-contained  
- Document non-trivial functions with JSDoc-style comments

### Pull Request Process

1. Show the work in screenshots
2. Request review from another collaborator  
3. Wait for approval before merging
